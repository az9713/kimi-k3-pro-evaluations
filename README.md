# Kimi K3.1 Pro evaluations

Summaries of three YouTube reviews that test Moonshot's Kimi K3.1 Pro against Claude Opus 5.5 and other leading models, plus a cross-review synthesis. Every screenshot is a frame taken from the reviewed video and links to its timestamp.

Live site: https://az9713.github.io/kimi-k3-pro-evaluations/

## Pages

- [Synthesis: Kimi K3.1 Pro Verdict](https://az9713.github.io/kimi-k3-pro-evaluations/): each host's sentiment, the consensus, and head-to-head against Opus 5.5, Gemini 4, DeepSeek 4.1, GPT-6 Astra and Kimi K3.
- [13 Long Tasks (PE)](https://az9713.github.io/kimi-k3-pro-evaluations/pe.html)
- [Five Builds (Barty)](https://az9713.github.io/kimi-k3-pro-evaluations/barty.html)
- [3D Gauntlet (Stefan)](https://az9713.github.io/kimi-k3-pro-evaluations/stefan.html)
